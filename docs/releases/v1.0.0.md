# sagarmatha-microbiome-analysis v1.0.0 — draft release notes

Not released. This journal-associated resource for the Sagarmatha (Mount Everest)
microbiome study contains reviewed analytical workflows, required
configuration, environments, tests, synthetic fixtures and technical documentation.
Study inputs, metadata, processed biological data, generated figures/tables,
research reports, manuscript drafts, handoffs and internal planning remain private.

Authorized external inputs are required for scientific runs. The intended public
policy is controlled access / available upon reasonable request to the authors,
subject to applicable permissions and data-use conditions. Alex Prima will receive
and coordinate requests at [alexprima@student.ub.ac.id](mailto:alexprima@student.ub.ac.id)
or [alex.prima@uq.net.au](mailto:alex.prima@uq.net.au). Component-specific conditions
remain pending verification before provision. Request coordination is not unrestricted redistribution authority
and does not guarantee approval. Study data, metadata and restricted processed
data remain excluded. See the [approved public statement](../release-data-requirements.md).
The original window
CSV is excluded; its six predefined windows remain in the generator, with
[regeneration instructions](../public-workflow.md#window-csv-regeneration).
The original private repository and history are not part of the public archive.

Software license: MIT. Separate data/annotation terms and verified public repository URL
remain pending. The repository name is approved; no GitHub owner is assumed. Release date and Zenodo DOI will be supplied only after the
corresponding approved actions. See [release gates](../public-release-checklist.md).

Public Makefile cleanup: the obsolete `make report` target is omitted. No report
template is supplied, and retained analytical commands are unchanged. Assembly
uses `Makefile.public` as root `Makefile`; the private original remains preserved.

Public RF tests now use explicitly fictional inputs through the unchanged RF
implementation. They verify software behavior without requiring study data;
production scientific validation remains separate. See [synthetic validation](../random-forest-methods.md#public-synthetic-validation).
